# akifgulluoglu.com.tr

Akif Güllüoğlu kişisel sitesi, Next.js + Tailwind v4. Tüm içerik `src/person.json` içindedir (Zod ile doğrulanır, `src/lib/person.ts`).

Tasarım dili "Profil raporu": koyu masa üzerinde üst üste dizilmiş rapor sayfaları, içindekiler tablosu, kırmızı defter kenar çizgisi, cetvel satırları ve toplam satırında muhasebe usulü çift çizgi. Bricolage Grotesque + Public Sans. Mono ve serif yok.

Doldurulacaklar: `seo.googleSiteVerification`, `socials`.
